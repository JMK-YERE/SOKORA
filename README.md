# SOKORA

SOKORA is a Tanzania-focused public marketplace concept combining short videos, product photos, and business discovery.

## First milestone
- React Native + Expo Android app foundation
- Public-first home feed layout
- Swahili-first interface
- Navigation shell for Home, Discover, Create/Sell, Inbox, and Profile

## Planned next milestones
1. Verify and run the mobile app.
2. Add real video and photo media support.
3. Add accounts, customer profiles, and business profiles.
4. Connect a backend API and inspect the existing Neon database before any schema changes.
5. Add product listings, messaging, moderation, and orders.
6. Evaluate hosting and media storage options before production deployment.

## Important
The first screen is a UI foundation, not a complete marketplace. Do not put database passwords, API keys, or other secrets in this repository.
